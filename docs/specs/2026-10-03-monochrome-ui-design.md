# 모노톤 화면 정리

## 요구와 방향

사용자는 기존 화면이 화려하여 최대한 모노톤으로 깔끔하게 정리하기를 원한다. 현재 스타일에는 흑백 팔레트 수정이 있지만 큰 홍보 제목, 검은 번호 블록, 짙은 보드와 장식 등 강한 시각 요소가 남아 있다. 흰색 화면과 카드, 얇은 회색 경계, 작은 제목, 균형 있는 간격을 사용하는 조용한 설정 화면으로 바꾼다.

## 구조

- HTML은 소개와 제목·장식만 정리한다. 큰 문구와 노선 그림 대신 ‘고속철도 모니터’ 제목 및 짧은 설명을 사용한다.
- CSS를 일관된 흑백 토큰으로 정돈한다. 검은색은 글자와 주 실행 버튼에 집중하고, 실행 요약도 밝은 카드로 만든다. 그라데이션, 장식 구멍·시간표 패널 효과, 굵은 테두리, 큰 숫자 블록, 점멸 애니메이션을 제거한다.
- 여정, 승객·좌석, 예약 방식, 계정 연결은 읽기 쉬운 크기의 제목과 구분선으로 구성한다. 선택 상태는 옅은 회색 바탕·체크 표시·굵기로 구분한다.
- 오류·예약 확인 필요는 흑백 안에서도 아이콘, 명확한 제목, 구분선으로 식별한다. 키보드 초점과 선택 상태는 유지한다.
- 역 검색·즐겨찾기 팝업은 밝은 바탕, 선명한 선택 상태, 작은 별표를 사용한다. 모바일에서 화면 폭을 벗어나지 않게 한다.
- 기존 요소 ID, 이름, ARIA 역할, JS 모듈과 백엔드 계약은 보존한다. 계정·여정 설정을 변경하지 않는다.

## 검증

데스크톱·모바일에서 전체 레이아웃, 역 팝업, 즐겨찾기, 초점 표시, 고급 설정을 확인한다. 검색·선택은 임시 브라우저 환경에서 확인하고 실제 감시·예약은 실행하지 않는다. 변경이 없는 서버에 대해 반복 테스트를 추가하지 않는다. 실제 페이지는 새로고침으로 수정된 정적 파일을 적용한다.
