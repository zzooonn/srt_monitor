# 모노톤 화면 미세 조정

사용자는 모노톤을 유지하되 단조로움을 줄이고 불필요한 설명을 없애기를 원한다. 전체 구조는 유지하며 화면의 밀도와 강조만 조절한다.

- 소개 문장과 설정 이전 배너를 제거한다. 이전 배너의 렌더링도 제거하여 다시 나타나지 않게 한다.
- 흰 카드 사이에 표면 명도, 작은 섹션 아이콘, 제목 위계, 부드러운 경계와 미세한 깊이를 추가한다. 색상 장식이나 큰 홍보 영역은 추가하지 않는다.
- 역 안내는 짧게 축약하고 출처는 접힌 안내 안에 둔다. 좌석 설명 등 장식 문구는 제거한다. 필요한 좌석 검증·결제·계정 입력 안내는 축약하거나 접힌 안내로 제공한다.
- 정상 연결, 저장 상태 문구를 짧게 바꾼다. 오류·예약 확인 필요·실행 잠금 메시지는 유지한다.
- 역 선택과 즐겨찾기, 모든 입력 필드·접근성·예약 로직·백엔드·사용자 설정을 보존한다.

구현 서브에이전트는 HTML/CSS만 수정한다. 주 에이전트는 배너 렌더링과 짧은 상태 문구를 수정한 뒤 데스크톱·모바일 실제 화면을 확인한다. 이후 검토 서브에이전트가 기능 참조와 화면 변경 범위를 검토한다. 실제 설정 저장·감시 시작·예약은 실행하지 않는다.
